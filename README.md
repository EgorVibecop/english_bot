# Бот для изучения английского

Telegram-бот с тремя разделами:

- **📚 Словарь** — 1769 слов по частоте употребления, три уровня сложности.
  Слово → перевод → короткая фраза-пример. Интервальный повтор и квиз.
- **⏳ Времена** — тренажёр на все 12 английских времён: предложение
  с пропуском, ответ вписывается текстом.
- **💬 Сленг** — 116 современных сокращений из переписки (btw, ngl, iykyk...).

Работает на бесплатном хостинге ботов или на своём компьютере.
Никаких платных сервисов и API-ключей — все словари лежат в репозитории.

---

## Развёртывание на хостинге (основной способ)

Бот полностью автономен: при первом запуске он сам создаёт базу данных
и наполняет её из JSON-файлов. Ничего вручную запускать не нужно.

1. Залей репозиторий на GitHub.
2. В панели хостинга (например bothost.ru) укажи:
   - **Git URL** — ссылка на репозиторий, ветка `main`
   - **Команда запуска** — `python bot.py`
   - **Переменная окружения** `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
3. Нажми Deploy.

### Чтобы прогресс не сбрасывался при передеплое

База данных намеренно **не** хранится в git: иначе каждый передеплой
затирал бы её версией из репозитория вместе со всем прогрессом.

По умолчанию база создаётся рядом с кодом (`english_bot.db`). Если хостинг
даёт постоянный диск (persistent volume), укажи путь к нему в переменной
окружения — тогда прогресс переживёт любой передеплой:

```
DB_PATH=/data/english_bot.db
```

Без этой переменной бот тоже работает, но при передеплое (не при обычном
рестарте) прогресс начнётся заново — сами слова и сокращения при этом
восстановятся автоматически.

## Запуск на своём компьютере

Нужен Python 3.10+. В терминале:

```bash
python -m venv venv
```

Активировать окружение — Windows (PowerShell): `venv\Scripts\Activate.ps1`,
Mac/Linux: `source venv/bin/activate`. Дальше:

```bash
pip install -r requirements.txt
```

Скопируй `.env.example` в `.env` и впиши туда токен от @BotFather:

```
BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Запуск (база соберётся сама при первом старте):

```bash
python bot.py
```

⚠️ Один и тот же токен нельзя использовать в двух местах одновременно.
Если бот уже работает на хостинге, останови его там перед локальным
запуском — иначе два экземпляра начнут «драться» за сообщения и ответы
будут приходить вперемешку.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и главное меню |
| `/word` | Новое слово |
| `/review` | Слова, которые пора повторить |
| `/quiz` | Квиз по словам, отмеченным «не знаю» |
| `/grammar` | Тренажёр времён |
| `/slang` | Сленговые сокращения |
| `/progress` | Статистика по всем разделам |

## Как это устроено

| Файл | Назначение |
|---|---|
| `words_top1000.json` | Список слов: частота (`rank`), порядок, уровень |
| `core_words.json` | Переводы служебных слов (артикли, предлоги, местоимения) |
| `translations_curated.json` | Переводы остальных слов |
| `examples.json` | Фраза-пример для каждого слова |
| `pos.json` | Часть речи (посчитана заранее через WordNet) |
| `slang.json` | Словарь сленговых сокращений |
| `grammar_exercises.json` | 180 упражнений на времена (по 15 на каждое) |
| `english_bot.db` | База SQLite: словарь + прогресс (создаётся автоматически) |

Все переводы выверены вручную: бесплатные API машинного перевода на
коротких словах ошибаются примерно в каждом шестом случае (`group` →
«экспозицие», `getting` → «чтобы я заказала»), поэтому от них отказались.

**Порядок слов.** Слова выдаются случайно, но одно и то же слово не
повторится раньше, чем через 200 других. Фиксированного порядка нет
намеренно — иначе после каждого сброса прогресса шли бы одни и те же
первые слова.

**Интервальный повтор** — упрощённая система Лейтнера: 6 «коробок»
с интервалами 1 → 2 → 4 → 7 → 14 → 30 дней. Ответил «не знаю» — слово
возвращается в начало.

**Уровни сложности** — не по частоте, а по реальной сложности лексики:

- Уровень 1 (843 слова) — база: `time`, `work`, `good`
- Уровень 2 (540 слов) — конкретная бытовая лексика: `fox`, `beer`, `train`
- Уровень 3 (386 слов) — абстракция и формальный регистр: `attorney`,
  `circumstances`, `revenue`

Из словаря исключены имена собственные, географические названия,
множественные формы (они не добавляют новых слов) и очевидные
заимствования, понятные без перевода (`radio`, `system`, `internet`).

## Как расширить словарь

```bash
pip install -r requirements-dev.txt
python generate_wordlist.py 3000
python seed_db.py
```

`requirements-dev.txt` нужен только для пересборки словаря на своём
компьютере — боту на сервере эти пакеты не требуются.

Новым словам нужно вручную добавить перевод в `translations_curated.json`
и фразу-пример в `examples.json` — `seed_db.py` в конце напечатает список
слов, для которых перевода не нашлось.

Прогресс по уже пройденным словам при этом не теряется: скрипт
идемпотентный и не трогает то, что уже заполнено.

## Возможные проблемы

- **«Не найден BOT_TOKEN»** — не задана переменная окружения `BOT_TOKEN`
  на хостинге либо не создан файл `.env` локально. Файл должен называться
  именно `.env` (не `.env.example` и не `.env.txt`).
- **Бот отвечает не на те сообщения, дублирует слова** — скорее всего,
  запущены два экземпляра с одним токеном (например, локально и на
  хостинге одновременно). Оставь только один.
- **Прогресс сбросился после передеплоя** — на хостинге нет постоянного
  диска либо не задана переменная `DB_PATH` (см. раздел о развёртывании).
