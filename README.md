# Бот для изучения английских слов (по частоте использования)

Telegram-бот, который учит топ-1000 самых частотных английских слов:
слово → перевод на русский → объяснение значения на английском.
Есть интервальный повтор (spaced repetition) и мини-квиз. Полностью
бесплатно, работает на твоём компьютере, никаких подписок.

---

## Что нужно один раз настроить

### 1. Установить Python

Нужен Python 3.10 или новее. Проверить: в терминале (Windows — PowerShell,
Mac — Terminal) набери:

```
python3 --version
```

Если команда не найдена — скачай Python с https://python.org (при установке
на Windows обязательно поставь галочку "Add Python to PATH").

### 2. Скачать проект и поставить зависимости

Распакуй присланный архив в удобную папку, затем в терминале:

```bash
cd путь/до/папки/engbot
python3 -m venv venv

# активировать окружение:
# Mac/Linux:
source venv/bin/activate
# Windows (PowerShell):
venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

### 3. Получить токен бота

1. В Telegram напиши боту **@BotFather**.
2. Команда `/newbot`, придумай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

### 4. Указать токен в проекте

Скопируй файл `.env.example` в `.env` и вставь туда токен:

```
BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### 5. Заполнить словарь переводами (один раз)

```bash
python seed_db.py
```

Скрипт пройдёт по 1000 словам: для ~220 самых частых служебных слов
(the, of, and, to...) переводы уже вшиты вручную (машинный перевод плохо
справляется с такими словами), а для остальных ~780 слов подтянет перевод
и объяснение через два бесплатных сервиса (dictionaryapi.dev и MyMemory
Translation). Это займёт **10–15 минут** из-за пауз между запросами
(чтобы не превысить бесплатный лимит). Прогресс печатается построчно.

Если часть слов не переведётся (бывает при сбоях API) — скрипт в конце
покажет список и подскажет запустить `python seed_db.py` ещё раз: уже
готовые слова он не трогает, дозагрузит только недостающие.

### 6. Запустить бота

```bash
python bot.py
```

В терминале появится "Бот запущен". Открой своего бота в Telegram и
нажми **Start**.

Бот работает, пока запущен этот терминал. Закрыл терминал — бот
остановился. Для более "постоянной" работы на своём компьютере можно:
- **Mac/Linux:** запустить через `nohup python bot.py &` или в `screen`/`tmux`,
  чтобы бот продолжал работать после закрытия окна терминала.
- **Windows:** можно оставить окно PowerShell свёрнутым, или добавить
  запуск через Планировщик заданий при входе в систему.

Для домашнего использования обычно достаточно просто держать терминал
открытым, когда собираешься заниматься.

## Как пользоваться ботом

- **/start** — приветствие и главное меню (кнопки внизу экрана).
- **📖 Новое слово** (`/word`) — следующее слово по частоте: слово,
  перевод на русский, объяснение на английском. После него нажми
  «✅ Знаю» или «❌ Не знаю» — от этого зависит, когда слово покажется
  на повторении.
- **🔁 Повторить** (`/review`) — слова, которые пора повторить (по системе
  интервального повторения: чем увереннее ты знаешь слово, тем реже оно
  повторяется).
- **🧠 Квиз** (`/quiz`) — 8 вопросов с вариантами ответа по уже пройденным
  словам, засчитывается результат.
- **📊 Прогресс** (`/progress`) — сколько слов выучено/в процессе, сколько
  ждёт повторения.

## Как это устроено (кратко)

- `words_top1000.json` — список слов, отсортированный по реальной частоте
  использования в английском (построен через библиотеку `wordfreq`,
  которая использует данные крупных языковых корпусов).
- `core_words.json` — вручную выверенные переводы/объяснения для топ-220
  служебных слов.
- `english_bot.db` — база SQLite: словарь + прогресс каждого пользователя
  (создаётся автоматически). Всё хранится локально у тебя на компьютере.
- Интервальный повтор реализован по упрощённой системе Лейтнера: 6 "коробок"
  с интервалами 1 → 2 → 4 → 7 → 14 → 30 дней. Ответил "не знаю" — слово
  возвращается в начало.

## Как расширить словарь (топ-3000 / топ-5000 слов)

```bash
python generate_wordlist.py 3000   # пересоберёт words_top1000.json на 3000 слов
python seed_db.py                  # доучит переводы только для новых слов
```

Уже пройденный прогресс по старым словам не потеряется.

## Возможные проблемы

- **"Не найден BOT_TOKEN"** — не создан `.env` файл или в нём опечатка. Файл
  должен называться именно `.env` (а не `.env.example` или `.env.txt`).
- **seed_db.py показывает "⚠ перевод не получен" для многих слов** — скорее
  всего, кончился бесплатный дневной лимит переводческого API либо нет
  интернета. Запусти скрипт повторно на следующий день или позже —
  недостающие слова доберутся.
- **Бот не отвечает в Telegram** — проверь, что терминал с `python bot.py`
  всё ещё открыт и не показал ошибку.

## Идеи для развития (когда захочется большего)

- Ежедневная рассылка N новых слов по расписанию (например, через
  `JobQueue` в `python-telegram-bot`).
- Добавить озвучку слов (TTS) или произношение через API.
- Экспорт словаря в Anki (.apkg) для занятий вне бота.
- Несколько тематических списков (например, для соц. наук — как в
  программе делового английского, которую мы уже обсуждали).
